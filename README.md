Cybersecurity Asset Inventory System
📌 Project Overview
This project is a Cybersecurity Asset Inventory System designed to help organizations manage their IT assets such as computers, servers, routers, switches, and applications.
It provides functionalities to add, search, update, delete, and display asset information, along with a security summary based on risk levels and security status.

🎯 Features
Add new assets with validation
Display all assets in a formatted inventory
Search assets by Asset ID
Update asset details
Delete assets
Generate a security summary (risk levels & security status)
Input validation for:
Asset Type
Risk Level
Security Status
IP Address format
